# Travel Atlas

Fifteen years, three countries, one dataset: every place I've lived, studied, worked, and wandered — mapped.

**Interactive map:** https://sharmauncw.github.io/atlas/

## What's here
- `data/places.json` — the dataset behind the map. Every place carries a category (lived / studied / worked / visited / recurring / upcoming), an era label, a note, and a source tag.
- 26 city pins, 11 explored regions, 7 "where next?" candidates (and counting — it's a living dataset).

## Method
Every entry is sourced — receipts, photo metadata, public records, and my own word — and tagged with its source. City-level only; nothing private. Places I'm unsure of are marked as regions ("cities TBC") rather than invented as pins.

Built as a companion to my institutional-research work: same discipline, personal data.
